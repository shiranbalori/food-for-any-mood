# FOOD FOR ANY MOOD

AI-powered recipe assistant that generates personalized recipes based on available ingredients, mood, cooking time, and dietary preferences.

## Features

- AI recipe generation
- Mood-based cooking recommendations
- Dairy / Meat / Parve support
- Gluten-free filtering
- Nutrition insights
- Shopping list generation
- Weekly meal planner
- Community recipe sharing
- Spotify and YouTube recommendations
- PWA installation support

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Python
- FastAPI
- Gemini API

Database:
- Supabase

Deployment:
- Vercel
- Render
